# Justin Philips CRM v3
Centrale Supabase-versie met beveiligde login, gedeelde data op meerdere apparaten, klantdossiers, opdrachten bewerken, klant zoeken bij opdrachten, alfabetische klantselectie en de statussen Offerte, Ingepland, Moet nog op inspectie, Service, Gefactureerd en Betaald.

De frontend bevat alleen de Supabase publishable key. De database is beschermd met Supabase Authentication en Row Level Security. Plaats nooit een secret/service_role key in GitHub.
